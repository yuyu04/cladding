## 5. Verdict

- **Cost:** B cuts the recurring per-read spend on the canonical spec by **~47%** (786 tokens/read). The saving recurs on every session/feature dispatch — it is not one-time.
- **Performance:** fewer input tokens per dispatch → proportionally lower input cost and faster time-to-first-token. The only added work is a one-time Haiku translation at init/refine (human view), which the model never reads.
- **결과물 (output):** the English canonical is the SSoT the model reads; `docs/project-context.ko.md` is a faithful human view (see the fixtures in `scripts/i18n-ab/`). Same meaning, fewer machine-read tokens.
- **Caveat:** tiktoken proxy + fixed representative fixtures (no API key in this run). Claude's Korean tokenization is heavier, so real savings are at least those shown.
